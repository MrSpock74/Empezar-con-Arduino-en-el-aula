Un LED con pulsador

Ahora la placa también «escucha»: el LED se enciende solo mientras mantienes pulsado el botón. Es tu primera entrada digital.

⏱ 1 sesión (55 min)🌱 Nivel inicial🔌 UNO y ESP32 STEAMakers🧩 Bloques y código

Qué vamos a hacer

Aprenderás

  • La diferencia entre una salida (LED) y una entrada (pulsador).
  • Qué hace una resistencia pull-down y por qué un pin sin conectar «flota».
  • Tomar decisiones con la estructura si… hacer… sino… (condicional).
  • Por qué la ESP32 trabaja con 3,3 V y no con 5 V.

Materiales

  • Placa Arduino UNO o ESP32 STEAMakers
  • Cable USB
  • Protoboard
  • 1 LED de 5 mm
  • 1 resistencia de 220 Ω
  • 1 resistencia de 10 kΩ
  • 1 pulsador de 4 patillas
  • Cables macho-macho

Montaje y programa

Elige tu placa: el esquema, los bloques y el código cambian con ella.

Variante con la shield Imagina TdR STEAM

En la shield Imagina TdR STEAM ya hay un pulsador en D2 (otro en D7) y un LED rojo en D12: usa exactamente los mismos pines que en la protoboard y no necesitas montar nada.

2 · Programa en bloques

Abre el editor de STEAMakersBlocks para Arduino UNO (modo demostración, sin cuenta; para guardar tus proyectos hay que iniciar sesión).

  1. En Bucle coloca un bloque si de Control y, con el signo +, añádele la parte sino.
  2. En la condición de si encaja el bloque Pulsador de Sensores y elige su pin.
  3. En hacer pon un Led en ON; en sino, el mismo Led en OFF.
  4. Sube el programa. Mantén pulsado el botón: el LED luce; suéltalo: se apaga.

3 · El mismo programa en código (Arduino IDE)

digitalRead lee la entrada: devuelve HIGH si el botón está pulsado y LOW si no. El if / else es el bloque si / sino.

// Práctica 2 · LED con pulsador
// Placa: Arduino UNO
// Manuel Romero Fraidía · CC BY-NC-SA 4.0 · https://github.com/MrSpock74/Empezar-con-Arduino-en-el-aula

const int LED = 12;      // LED en D12
const int BOTON = 2;     // pulsador en D2 (con resistencia pull-down de 10 kΩ)

void setup() {
  pinMode(LED, OUTPUT);
  pinMode(BOTON, INPUT);
}

void loop() {
  if (digitalRead(BOTON) == HIGH) {
    digitalWrite(LED, HIGH);
  } else {
    digitalWrite(LED, LOW);
  }
}

En la ESP32 los pines trabajan a 3,3 V. Alimenta el pulsador con el pin 3V3; si le llevas 5 V, puedes dañar el pin.

3 · El mismo programa en código (Arduino IDE)

digitalRead lee la entrada: devuelve HIGH si el botón está pulsado y LOW si no. El if / else es el bloque si / sino.

// Práctica 2 · LED con pulsador
// Placa: ESP32 STEAMakers
// Manuel Romero Fraidía · CC BY-NC-SA 4.0 · https://github.com/MrSpock74/Empezar-con-Arduino-en-el-aula

const int LED = 19;      // D12 de la placa = GPIO 19
const int BOTON = 26;    // D2 de la placa = GPIO 26 (con pull-down de 10 kΩ, alimentado a 3V3)

void setup() {
  pinMode(LED, OUTPUT);
  pinMode(BOTON, INPUT);
}

void loop() {
  if (digitalRead(BOTON) == HIGH) {
    digitalWrite(LED, HIGH);
  } else {
    digitalWrite(LED, LOW);
  }
}

Retos

  1. Al revés. Haz que el LED esté encendido siempre y se apague mientras pulsas.
  2. Interruptor. Que cada pulsación cambie el estado del LED (encendido ↔ apagado). Pista: necesitarás una variable y esperar a que se suelte el botón.
  3. Temporizador. Al pulsar, el LED se enciende tres segundos y se apaga solo.
  4. Dos botones. Con la shield, usa D2 para encender y D7 para apagar.

En el aula

Organización

  • Parejas con roles rotativos: quien monta y quien programa, y se cambian en cada práctica.
  • Cada pareja entrega su montaje funcionando antes de pasar a los retos.
  • Ofrece el programa en bloques o en código según el nivel; el mismo reto sirve para los dos.

Qué observar (evaluación)

  • Distingue entrada y salida en su montaje y lo explica con sus palabras.
  • Monta el pulsador con la resistencia pull-down.
  • Programa el condicional correctamente y lo prueba.
  • Explica qué ocurre si quita la resistencia de 10 kΩ.
Estos criterios son observables y se pueden adaptar a tu programación didáctica y a una rúbrica competencial (pensamiento computacional, resolución de problemas, trabajo cooperativo y uso seguro de la electrónica).

Errores frecuentes

El LED parpadea o cambia solo

El pin de entrada está «flotando»: falta la resistencia de 10 kΩ a GND o está mal conectada.

El LED siempre está encendido

Las patillas del pulsador están en el mismo lado y siempre hacen contacto. Gíralo 90° o usa patillas opuestas en diagonal.

Nada responde en la ESP32

Comprueba que el pulsador va a 3V3 y no a 5V, y que el pin del programa es el 26 (D2), no el 2.

El LED hace lo contrario

Mira la casilla Invertir del bloque Pulsador: debe estar sin marcar con este montaje.
