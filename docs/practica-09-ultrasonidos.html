Medir distancias con ultrasonidos (HC-SR04)

El sensor emite un pitido que no oímos, espera el eco y calcula la distancia. Medirás en el monitor serie y harás una alarma de proximidad.

⏱ 1–2 sesiones🌱 Nivel intermedio🔌 UNO y ESP32 STEAMakers🧩 Bloques y código

Qué vamos a hacer

Aprenderás

  • Cómo un sensor mide distancias con el tiempo de ida y vuelta de un sonido.
  • Mostrar datos en el monitor serie para depurar tu programa.
  • Comparar un valor medido con un umbral para activar una alarma.
  • Qué es un divisor de tensión y por qué la ESP32 lo necesita con este sensor.

Materiales

  • Placa Arduino UNO o ESP32 STEAMakers
  • Cable USB
  • Protoboard
  • Sensor HC-SR04
  • 1 LED y 1 resistencia de 220 Ω (para la alarma)
  • Solo ESP32: 1 resistencia de 1 kΩ y 1 de 2 kΩ
  • Cables macho-macho y macho-hembra
  • Regla o cinta métrica

  4. Sube el programa, abre la Consola del editor y acerca la mano al sensor: verás cómo cambia la distancia.
  5. Variante alarma: sustituye el contenido del bucle por un si… hacer… sino… donde la condición compara la distancia con < 15.

Variante: alarma de proximidad

3 · El mismo programa en código (Arduino IDE)

El sensor se dispara con un pulso de 10 µs en TRIG y devuelve en ECHO un pulso cuya duración es el tiempo de ida y vuelta. Distancia = tiempo × 0,0343 cm/µs ÷ 2. Con pulseIn se mide ese tiempo; si no llega eco, devuelve 0.

// Práctica 9 · Distancia con HC-SR04
// Placa: Arduino UNO
// Manuel Romero Fraidía · CC BY-NC-SA 4.0 · https://github.com/MrSpock74/Empezar-con-Arduino-en-el-aula

const int TRIG = 3;
const int ECHO = 5;

float medirDistancia() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long duracion = pulseIn(ECHO, HIGH, 30000);  // µs; 0 si no hay eco
  return duracion * 0.0343 / 2;                // cm
}

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
}

void loop() {
  float cm = medirDistancia();
  Serial.println(cm);
  delay(500);
}

// Práctica 9 · Alarma de proximidad
// Placa: Arduino UNO
// Manuel Romero Fraidía · CC BY-NC-SA 4.0 · https://github.com/MrSpock74/Empezar-con-Arduino-en-el-aula

const int TRIG = 3;
const int ECHO = 5;
const int LED = 12;        // LED de la alarma
const float UMBRAL = 15; // cm

float medirDistancia() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long duracion = pulseIn(ECHO, HIGH, 30000);  // µs; 0 si no hay eco
  return duracion * 0.0343 / 2;                // cm
}

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(LED, OUTPUT);
}

void loop() {
  float cm = medirDistancia();
  Serial.println(cm);
  // cm > 0 evita que «sin eco» (0) active la alarma
  if (cm > 0 && cm < UMBRAL) {
    digitalWrite(LED, HIGH);
  } else {
    digitalWrite(LED, LOW);
  }
  delay(100);
}

ESP32 STEAMakers

1 · Conexión

ComponentePin de la placa
HC-SR04 VCC5V
HC-SR04 TRIGD3 (= GPIO 25)
HC-SR04 ECHOD5 (= GPIO 16), a través del divisor
HC-SR04 GNDGND
LED de la alarma (con 220 Ω)D12 (= GPIO 19)
El HC-SR04 se alimenta a 5 V y su pin ECHO devuelve 5 V, pero los pines de la ESP32 soportan 3,3 V. Pon el divisor de tensión (1 kΩ en serie y 2 kΩ a GND) para reducirlos a unos 3,3 V. Si tu sensor es una versión de 3,3 V (HC-SR04P o similar), no lo necesitas. El LED de la alarma (D12) no se dibuja en el esquema: se monta como en la práctica 1.

// Placa: ESP32 STEAMakers
// Manuel Romero Fraidía · CC BY-NC-SA 4.0 · https://github.com/MrSpock74/Empezar-con-Arduino-en-el-aula

const int TRIG = 25;     // D3 de la placa = GPIO 25
const int ECHO = 16;     // D5 de la placa = GPIO 16 (con divisor 1 kΩ / 2 kΩ)

float medirDistancia() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long duracion = pulseIn(ECHO, HIGH, 30000);  // µs; 0 si no hay eco
  return duracion * 0.0343 / 2;                // cm
}

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
}

void loop() {
  float cm = medirDistancia();
  Serial.println(cm);
  delay(500);
}

Retos

  1. Mide y compara. Mide con el sensor objetos a 10, 20 y 50 cm y compara con la regla. ¿Cuál es el error?
  2. Alarma de aparcamiento. Enciende el LED si hay algo a menos de 15 cm y haz que parpadee más rápido cuanto más cerca esté.
  3. Umbral ajustable. Con la shield, usa los pulsadores D2 y D7 para subir o bajar el umbral de la alarma.
  4. Sonido. Añade un zumbador (D8 en la shield) que suene cuando salte la alarma.

En el aula

Organización

  • Parejas con roles rotativos: quien monta y quien programa, y se cambian en cada práctica.
  • Cada pareja entrega su montaje funcionando antes de pasar a los retos.
  • Ofrece el programa en bloques o en código según el nivel; el mismo reto sirve para los dos.

Qué observar (evaluación)

  • Conecta el sensor con los cuatro cables correctos (y el divisor, en la ESP32).
  • Lee las medidas en el monitor serie y las contrasta con una regla.
  • Programa la alarma con un umbral y explica qué ocurre si lo cambia.
  • Explica con sus palabras cómo mide el sensor.
Estos criterios son observables y se pueden adaptar a tu programación didáctica y a una rúbrica competencial (pensamiento computacional, resolución de problemas, trabajo cooperativo y uso seguro de la electrónica).

Errores frecuentes

Siempre mide 0 o valores absurdos

Comprueba que TRIG y ECHO no están intercambiados, que GND está conectado y que hay algo delante a entre 2 cm y 4 m.

Las medidas saltan mucho

Las superficies blandas (ropa, cortinas) o inclinadas devuelven mal el eco. Prueba con una caja o un libro.

En la ESP32 funciona un rato y luego falla

Revisa el divisor de tensión en ECHO. Sin él, el pin recibe 5 V y se puede dañar.

La alarma se activa sin nada delante

Cuando no hay eco, la lectura puede ser 0, que es menor que 15. Comprueba qué valor devuelve tu sensor sin obstáculo y añade la condición «mayor que 0».
