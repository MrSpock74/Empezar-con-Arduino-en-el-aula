Sensor de luz (LDR): una farola automática

Una LDR es una resistencia que cambia con la luz. Medirás el nivel de luz con el monitor serie y harás una farola que se enciende sola cuando oscurece.

⏱ 1–2 sesiones🌱 Nivel inicial🔌 UNO y ESP32 STEAMakers🧩 Bloques y código

Qué vamos a hacer

Aprenderás

  • Qué es una LDR y cómo cambia su resistencia con la luz.
  • Cómo un divisor de tensión convierte esa resistencia en una tensión que la placa puede leer.
  • Medir con el monitor serie y escoger un umbral a partir de datos reales.
  • Pasar un valor a porcentaje para trabajar con él con más facilidad.

Materiales

  • Placa Arduino UNO o ESP32 STEAMakers
  • Cable USB
  • Protoboard
  • 1 LDR (fotorresistencia)
  • 1 resistencia de 10 kΩ
  • 1 LED y 1 resistencia de 220 Ω (para la farola)
  • Cables macho-macho

Montaje y programa

Elige tu placa: el esquema, los bloques y el código cambian con ella.

2 · Programa en bloques

Abre el editor de STEAMakersBlocks para Arduino UNO (modo demostración, sin cuenta; para guardar tus proyectos hay que iniciar sesión).

  1. Primero mide. En Inicializar pon Iniciar baudios 9600 (Comunicaciones).
  2. En Bucle añade Enviar línea y, en su hueco, el bloque Nivel de luz (LDR) de Sensores con el pin A1 y el rango sin porcentaje (0..1023, o 0..4095 en la ESP32). Añade Esperar 300 ms.
  3. Sube el programa, abre la Consola y tapa la LDR con la mano o ilumínala con la linterna del móvil. Anota el valor con luz y con oscuridad.
  4. Después, la farola. Sustituye el bucle por un si… hacer… sino… cuya condición compare el Nivel de luz en porcentaje con < 30; en hacer, Led ON; en sino, Led OFF.
  5. Prueba a tapar la LDR: el LED debería encenderse. Ajusta el 30 con los valores que anotaste.

3 · El mismo programa en código (Arduino IDE)

Con analogRead medimos la tensión del divisor: cuanta más luz, más alta es la lectura. map la pasa a porcentaje (0–100) y el if / else decide si encender el LED. En la ESP32 el conversor llega a 4095 en lugar de 1023.

// Práctica 6 · Medir la luz con una LDR
// Placa: Arduino UNO
// Manuel Romero Fraidía · CC BY-NC-SA 4.0 · https://github.com/MrSpock74/Empezar-con-Arduino-en-el-aula

const int LDR = A1;      // LDR con divisor de 10 kΩ en A1

void setup() {
  Serial.begin(9600);
}

void loop() {
  Serial.println(analogRead(LDR));   // 0 (oscuridad) a 1023 (mucha luz)
  delay(300);
}

Segundo programa: farola automática

// Práctica 6 · Farola automática con LDR
// Placa: Arduino UNO
// Manuel Romero Fraidía · CC BY-NC-SA 4.0 · https://github.com/MrSpock74/Empezar-con-Arduino-en-el-aula

const int LDR = A1;      // LDR con divisor de 10 kΩ en A1
const int LED = 12;      // LED de la farola
const int UMBRAL = 30;  // por debajo de este porcentaje de luz, se enciende

void setup() {
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int luz = map(analogRead(LDR), 0, 1023, 0, 100);   // porcentaje de luz
  Serial.println(luz);
  if (luz < UMBRAL) {
    digitalWrite(LED, HIGH);
  } else {
    digitalWrite(LED, LOW);
  }
  delay(100);
}

Retos

  1. Ajusta tu umbral. Mide en tu aula la luz de un día soleado, con la luz artificial y en penumbra, y decide cuál debería ser el umbral de tu farola.
  2. Indicador de luz. Con tres LED, que se enciendan uno, dos o tres según la cantidad de luz, como un nivel de volumen (reto de la versión de 2018).
  3. Luz de noche. Combina esta práctica con la del LED RGB: que se encienda un color suave solo cuando oscurece.
  4. Evita el parpadeo. Si la luz está justo en el umbral, el LED parpadea. Usa dos umbrales (uno para encender y otro para apagar) para evitarlo.

En el aula

Organización

  • Parejas con roles rotativos: quien monta y quien programa, y se cambian en cada práctica.
  • Cada pareja entrega su montaje funcionando antes de pasar a los retos.
  • Ofrece el programa en bloques o en código según el nivel; el mismo reto sirve para los dos.

Qué observar (evaluación)

  • Monta el divisor de tensión con la LDR y la resistencia de 10 kΩ y explica qué hace cada una.
  • Mide valores reales con luz y con oscuridad y los usa para elegir el umbral.
  • Programa la farola y la comprueba tapando la LDR.
  • Explica por qué la lectura cambia con la luz.
Estos criterios son observables y se pueden adaptar a tu programación didáctica y a una rúbrica competencial (pensamiento computacional, resolución de problemas, trabajo cooperativo y uso seguro de la electrónica).

Errores frecuentes

La lectura no cambia al tapar la LDR

Comprueba que el cable a A1 sale del punto donde se unen la LDR y la resistencia de 10 kΩ, y que están en la misma fila de la protoboard.

El LED se enciende con luz y se apaga a oscuras

Se ha intercambiado el orden: la LDR debe ir al positivo y los 10 kΩ a GND. Si los cambias, la lectura sube al oscurecer.

El LED parpadea en penumbra

La luz está cerca del umbral. Cambia el umbral o usa dos umbrales distintos para encender y apagar.

El porcentaje no llega a 100 o a 0

Es normal: una LDR con 10 kΩ casi nunca cubre todo el rango. Usa tus valores medidos para ajustar el umbral.
