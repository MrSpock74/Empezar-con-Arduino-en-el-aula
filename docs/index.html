Empezar con Arduino en el aula

Trece prácticas para iniciarse en la robótica educativa con Arduino UNO y la ESP32 STEAMakers, programando con bloques (STEAMakersBlocks) o con código. Cada práctica trae su esquema de conexión, el programa para las dos placas, retos y orientaciones para llevarla al aula.

Antes de empezar

Qué necesitas

  • Una placa Arduino UNO o una ESP32 STEAMakers, con cable USB.
  • Navegador Chrome o Edge para subir los programas desde STEAMakersBlocks.
  • Protoboard, cables y componentes de cada práctica; o la shield Imagina TdR STEAM.

Dos placas, un mismo programa

  • Los pines de la ESP32 STEAMakers tienen el mismo formato que el UNO (D2, D3…), pero internamente son otros GPIO.
  • La ESP32 trabaja a 3,3 V: cuidado con las señales de 5 V.
  • Cada práctica indica las diferencias.
