LED RGB: mezclar colores con luz

Un LED RGB lleva tres LED en uno (rojo, verde y azul). Regulando cuánto brilla cada uno puedes crear cualquier color: la misma idea que usan las pantallas.

⏱ 1 sesión (55 min)🌱 Nivel inicial🔌 UNO y ESP32 STEAMakers🧩 Bloques y código

Qué vamos a hacer

Aprenderás

  • Cómo se forman los colores sumando luz roja, verde y azul (síntesis aditiva).
  • La diferencia entre un LED RGB de cátodo común y uno de ánodo común.
  • Usar tres salidas PWM a la vez y valores de 0 a 255 para cada color.
  • Por qué cada color necesita su propia resistencia.

Materiales

  • Placa Arduino UNO o ESP32 STEAMakers
  • Cable USB
  • Protoboard
  • 1 LED RGB de cátodo común
  • 3 resistencias de 220 Ω
  • Cables macho-macho

Montaje y programa

Elige tu placa: el esquema, los bloques y el código cambian con ella.

Arduino UNO

1 · Conexión

ComponentePin de la placa
Rojo (a través de 220 Ω)D6
Verde (a través de 220 Ω)D9
Azul (a través de 220 Ω)D10
Cátodo común (la patilla más larga)GND
Variante con la shield Imagina TdR STEAM

La shield Imagina TdR STEAM incluye un LED RGB en D6, D9 y D10 (los mismos pines que en la protoboard). Comprueba en tu modelo si es de cátodo o de ánodo común y elige el tipo correcto en el bloque.

2 · Programa en bloques

Abre el editor de STEAMakersBlocks para Arduino UNO (modo demostración, sin cuenta; para guardar tus proyectos hay que iniciar sesión).

  1. En Bucle coloca un bloque Led RGB (Actuadores), elige Cátodo común y los pines de rojo, verde y azul.
  2. Pon R = 255, G = 0, B = 0: rojo al máximo y los demás apagados.
  3. Debajo añade Esperar 1000 ms.
  4. Duplica el bloque dos veces: uno con G = 255 (verde) y otro con B = 255 (azul), cada uno con su espera.
  5. Sube el programa: el LED debería pasar por rojo, verde y azul. Prueba ahora valores intermedios, como 255, 255, 0.

3 · El mismo programa en código (Arduino IDE)

Cada color es una salida PWM con un valor de 0 a 255. La función color(r, g, b) evita repetir tres líneas cada vez. Si tu LED fuese de ánodo común, los valores se invertirían: sería 255 - valor y el ánodo iría a 5 V (3V3 en la ESP32).

// Práctica 5 · LED RGB de cátodo común
// Placa: Arduino UNO
// Manuel Romero Fraidía · CC BY-NC-SA 4.0 · https://github.com/MrSpock74/Empezar-con-Arduino-en-el-aula

const int ROJO = 6;    // D6
const int VERDE = 9;   // D9
const int AZUL = 10;    // D10

// Pone el LED RGB (cátodo común) al color indicado: cada valor va de 0 a 255
void color(int rojo, int verde, int azul) {
  analogWrite(ROJO, rojo);
  analogWrite(VERDE, verde);
  analogWrite(AZUL, azul);
}

void setup() {
  pinMode(ROJO, OUTPUT);
  pinMode(VERDE, OUTPUT);
  pinMode(AZUL, OUTPUT);
}

void loop() {
  color(255, 0, 0);   // rojo
  delay(1000);
  color(0, 255, 0);   // verde
  delay(1000);
  color(0, 0, 255);   // azul
  delay(1000);
}

ESP32 STEAMakers

1 · Conexión

ComponentePin de la placa
Rojo (a través de 220 Ω)D6 (= GPIO 27)
Verde (a través de 220 Ω)D9 (= GPIO 13)
Azul (a través de 220 Ω)D10 (= GPIO 5)
Cátodo común (la patilla más larga)GND
Para usar analogWrite() en código con la ESP32 necesitas la versión 3.x del núcleo ESP32 para Arduino. El GPIO 5 (D10) también se usa al arrancar, pero con una resistencia hacia el LED no suele dar problemas.

// Práctica 5 · LED RGB de cátodo común
// Placa: ESP32 STEAMakers (núcleo ESP32 3.x)
// Manuel Romero Fraidía · CC BY-NC-SA 4.0 · https://github.com/MrSpock74/Empezar-con-Arduino-en-el-aula

const int ROJO = 27;    // D6 de la placa = GPIO 27
const int VERDE = 13;   // D9 de la placa = GPIO 13
const int AZUL = 5;    // D10 de la placa = GPIO 5

// Pone el LED RGB (cátodo común) al color indicado: cada valor va de 0 a 255
void color(int rojo, int verde, int azul) {
  analogWrite(ROJO, rojo);
  analogWrite(VERDE, verde);
  analogWrite(AZUL, azul);
}

void setup() {
  pinMode(ROJO, OUTPUT);
  pinMode(VERDE, OUTPUT);
  pinMode(AZUL, OUTPUT);
}

void loop() {
  color(255, 0, 0);   // rojo
  delay(1000);
  color(0, 255, 0);   // verde
  delay(1000);
  color(0, 0, 255);   // azul
  delay(1000);
}

Retos

  1. Paleta. Consigue amarillo (255, 255, 0), cian (0, 255, 255), magenta (255, 0, 255) y blanco, y comprueba que coinciden con lo que ves.
  2. Tu color. Elige un color que te guste, busca sus valores RGB en internet y reprodúcelo.
  3. Arcoíris. Haz un fundido suave de rojo a verde a azul usando una variable que cambie poco a poco.
  4. Mezclador. Con el potenciómetro de la práctica 4, elige el color del LED según la posición.

En el aula

Organización

  • Parejas con roles rotativos: quien monta y quien programa, y se cambian en cada práctica.
  • Cada pareja entrega su montaje funcionando antes de pasar a los retos.
  • Ofrece el programa en bloques o en código según el nivel; el mismo reto sirve para los dos.

Qué observar (evaluación)

  • Monta el LED RGB identificando cátodo y colores, con una resistencia por cada color.
  • Explica cómo se obtiene el amarillo y el blanco con los tres colores.
  • Programa una secuencia de colores y la modifica con otros valores.
  • Explica qué cambiaría con un LED de ánodo común.
Estos criterios son observables y se pueden adaptar a tu programación didáctica y a una rúbrica competencial (pensamiento computacional, resolución de problemas, trabajo cooperativo y uso seguro de la electrónica).

Errores frecuentes

Los colores salen cambiados

Los pines R, G y B no están en el orden esperado. Comprueba qué patilla es cada color en tu LED (el cátodo suele ser la más larga y está en segundo lugar).

Se enciende el contrario de lo pedido

Tu LED es de ánodo común: cambia el tipo en el bloque a «Ánodo» y conecta el ánodo a 5 V (3V3 en la ESP32).

Un color brilla mucho menos

Es normal que el azul y el verde luzcan más que el rojo. Si es muy diferente, revisa las tres resistencias.

No se enciende ninguno

Revisa que el cátodo común va a GND y que cada resistencia está en serie con su color.
