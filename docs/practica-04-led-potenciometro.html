El brillo de un LED con potenciómetro

Girando un potenciómetro regulas el brillo de un LED. Es tu primera entrada analógica y tu primera salida PWM: la base de casi cualquier regulador (volumen, velocidad, luz…).

⏱ 1 sesión (55 min)🌱 Nivel inicial🔌 UNO y ESP32 STEAMakers🧩 Bloques y código

Qué vamos a hacer

Aprenderás

  • La diferencia entre una señal digital (solo 0 o 1) y una analógica (muchos valores).
  • Cómo un potenciómetro reparte la tensión y qué lee la placa (0–1023 en el UNO, 0–4095 en la ESP32).
  • Qué es el PWM: regular el brillo encendiendo y apagando muy rápido.
  • Cambiar de escala un valor con el bloque mapear.

Materiales

  • Placa Arduino UNO o ESP32 STEAMakers
  • Cable USB
  • Protoboard
  • 1 LED de 5 mm
  • 1 resistencia de 220 Ω
  • 1 potenciómetro (por ejemplo, 10 kΩ)
  • Cables macho-macho

Montaje y programa

Elige tu placa: el esquema, los bloques y el código cambian con ella.

Arduino UNO

1 · Conexión

ComponentePin de la placa
LED (ánodo, a través de 220 Ω)D3 (PWM)
Cátodo del LEDGND
Potenciómetro, patilla central (cursor)A0
Potenciómetro, patilla extrema5V
Potenciómetro, otra patilla extremaGND
Variante con la shield Imagina TdR STEAM

La shield Imagina TdR STEAM trae un potenciómetro en A0. Para el LED conecta uno tuyo, con su resistencia, a D3 (admite PWM). El LED rojo de D12 también sirve, pero ese pin del UNO no admite PWM y solo verías encendido o apagado.

2 · Programa en bloques

Abre el editor de STEAMakersBlocks para Arduino UNO (modo demostración, sin cuenta; para guardar tus proyectos hay que iniciar sesión).

  1. En Bucle pon un bloque Led intensidad (PWM) (Actuadores) y elige el pin del LED.
  2. En su hueco Valor encaja un bloque mapear (Matemáticas).
  3. Dentro de mapear pon el bloque Potenciómetro (Sensores) con el pin A0 y el rango 0..1023 (en la ESP32, 0..4095).
  4. Rellena de 0 a 1023 (ESP32: 0 a 4095) a 0 a 255: el potenciómetro da valores grandes y el PWM solo admite de 0 a 255.
  5. Sube el programa y gira el potenciómetro: el brillo debe subir y bajar suavemente.

3 · El mismo programa en código (Arduino IDE)

analogRead devuelve un número según la posición del potenciómetro; map lo convierte de la escala del conversor a la del PWM (0–255) y analogWrite regula el brillo. En el UNO, el conversor llega a 1023; en la ESP32, a 4095.

// Práctica 4 · Brillo de un LED con potenciómetro
// Placa: Arduino UNO
// Manuel Romero Fraidía · CC BY-NC-SA 4.0 · https://github.com/MrSpock74/Empezar-con-Arduino-en-el-aula

const int LED = 3;       // LED en D3 (pin PWM)
const int POT = A0;      // potenciómetro en A0

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  int lectura = analogRead(POT);              // 0 a 1023
  int brillo = map(lectura, 0, 1023, 0, 255); // PWM: 0 a 255
  analogWrite(LED, brillo);
}

ESP32 STEAMakers

1 · Conexión

ComponentePin de la placa
LED (ánodo, a través de 220 Ω)D3 (= GPIO 25)
Cátodo del LEDGND
Potenciómetro, patilla central (cursor)A0 (= GPIO 2)
Potenciómetro, patilla extrema3V3 (¡no 5V!)
Potenciómetro, otra patilla extremaGND
Alimenta el potenciómetro con 3V3: la ESP32 no admite más de 3,3 V en una entrada analógica. Además, A0 es el GPIO 2, que pertenece al conversor ADC2: si más adelante usas el WiFi, esa lectura dejará de funcionar y tendrás que cambiar a A2 o A3. Para usar analogWrite() en código necesitas la versión 3.x del núcleo ESP32 para Arduino.

// Práctica 4 · Brillo de un LED con potenciómetro
// Placa: ESP32 STEAMakers (núcleo ESP32 3.x)
// Manuel Romero Fraidía · CC BY-NC-SA 4.0 · https://github.com/MrSpock74/Empezar-con-Arduino-en-el-aula

const int LED = 25;      // D3 de la placa = GPIO 25
const int POT = 2;       // A0 de la placa = GPIO 2 (potenciómetro alimentado a 3V3)

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  int lectura = analogRead(POT);              // 0 a 4095
  int brillo = map(lectura, 0, 4095, 0, 255); // PWM: 0 a 255
  analogWrite(LED, brillo);
}

Retos

  1. Brillo al revés. Haz que el LED brille más cuanto más hacia la izquierda gires el potenciómetro. Pista: invierte los valores de destino en mapear.
  2. Mostrar el valor. Envía la lectura al monitor serie y anota los valores mínimo y máximo que da tu potenciómetro.
  3. Dos LED. Con dos LED, que uno aumente su brillo mientras el otro lo disminuye.
  4. Apagado por umbral. Que el LED se apague del todo cuando el potenciómetro esté por debajo de un cuarto del recorrido.

En el aula

Organización

  • Parejas con roles rotativos: quien monta y quien programa, y se cambian en cada práctica.
  • Cada pareja entrega su montaje funcionando antes de pasar a los retos.
  • Ofrece el programa en bloques o en código según el nivel; el mismo reto sirve para los dos.

Qué observar (evaluación)

  • Conecta correctamente los tres terminales del potenciómetro y explica para qué sirve cada uno.
  • Distingue entre señal digital y analógica con un ejemplo de su montaje.
  • Explica por qué hay que «mapear» el valor del potenciómetro antes de usarlo en el LED.
  • Resuelve al menos un reto y lo explica a otra persona.
Estos criterios son observables y se pueden adaptar a tu programación didáctica y a una rúbrica competencial (pensamiento computacional, resolución de problemas, trabajo cooperativo y uso seguro de la electrónica).

Errores frecuentes

El LED no cambia de brillo, solo se enciende o se apaga

El pin del LED no admite PWM. En el UNO, usa uno marcado con «~» (3, 5, 6, 9, 10 u 11).

El brillo salta o parpadea

Revisa que el cable del cursor (patilla central) esté bien conectado a A0 y que las patillas no se toquen entre sí.

Girar el potenciómetro no hace nada en la ESP32

Comprueba que está alimentado a 3V3 y que has puesto el rango 0..4095 en el bloque del potenciómetro.

Al girar, el brillo varía solo en una parte del giro

Estás usando un rango de entrada que no corresponde a tu placa (1023 en el UNO, 4095 en la ESP32).
